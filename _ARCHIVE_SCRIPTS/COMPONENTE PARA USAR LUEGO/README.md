# COMPONENTE GUARDADO PARA USAR LUEGO

## HeroKV_3D_24Cards.jsx
- Cuadrícula 3D de 24 tarjetas a pantalla completa (6x4).
- Efecto hover 360° individual revelando palabras clave tácticas y badges amarillos neón (#e6fb04).
- Intercepción de scroll con bloqueo y animación de onda 3D que gira las 24 tarjetas 180° revelando la filosofía.
- Fondo de partículas Three.js reactivas al movimiento del cursor.

### Cómo reutilizarlo:
1. Importar HeroKV_3D_24Cards en App.jsx.
2. Usarlo en lugar del Hero principal.
